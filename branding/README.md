# Product identity

**Status:** documentation-only placeholder. **Milestones:** [M0](https://github.com/PlaybookMediaLLC/kaneo/issues/6), [M6](https://github.com/PlaybookMediaLLC/kaneo/issues/12).

This directory will contain **original**, Playbook-owned identity assets for the customer-facing feedback/product-management product. The final product name, logo and design language have not been selected.

## Intended scope

- Product brand guidelines, naming, colors, iconography, typography references and tone.
- Source files for web/feedback-widget assets, with license provenance.
- Customer-facing integration text such as "Connect Orchestrator.inc" or "Works with Claude Code" where accurate.
- Product-specific marketing copy and app icons only if a Playbook-owned companion actually ships.

## Boundaries

Do not copy UserJot assets, imply affiliation with Orchestrator, delete upstream attributions, or bundle proprietary third-party fonts/logos. The official Orchestrator desktop is **not** being modified or rebranded.

See [attribution](../docs/attribution.md). No branding assets have been created.
